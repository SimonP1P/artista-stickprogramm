1. Introduction to ADX
Welcome to BERNINA® ADX, a universal interface between the BERNINA® embroidery software and
BERNINA® embroidery systems. ADX stands for Artista Data eXchange and handles the connection
between computer and several embroidery devices.


1.1. Using this guide
BERNINA® ADX has flexible exchange capabilities, which make it easy to transfer or administer
designs on storage devices.

       This guide is divided into chapters that apply to the various features of design exchange and can
       be invoked by the F1 key or the help button.



2. Installing your Software
BERNINA® ADX is installed as an interface function library of the BERNINA® Embroidery Software.
For more details on software installation and computer requirements refer to the BERNINA®
Embroidery Software User Manual.


2.1. Installing BERNINA® ADX
The installation of BERNINA® ADX is part of the Setup CD of the BERNINA® Embroidery System.
See more details on the Setup CD.

For proper use of BERNINA® ADX, the following items have to be installed:

   ♦     BERNINA® Embroidery Software - Service Pack 3.1 or higher
   ♦     Acrobat Reader 4.0 or higher
   ♦     Microsoft ® ActiveSync Version 3.1 for Windows 95, Version 3.5 for Windows 98 ... or higher
   ♦     Microsoft ® Internet Explorer 5.0 or higher

Check the following setup:

   ♦     USB or serial cable is connected between BERNINA® Embroidery System and computer
   ♦     Both systems are switched on and ready

2.2. Setup Connections for artista 200
The communication between BERNINA® Embroidery Software and BERNINA® Embroidery System
devices like

   ♦     artista 200 sewing computer with embroidery module
   ♦     BERNINA® artista Design Card
   ♦     CD-ROM

will be done by Microsoft ® ActiveSync. A USB cable is used for the physical connection between your
computer and the BERNINA® Embroidery System.

2.2.1.     Microsoft ®ActiveSync
This software can be found on the Setup CD and has to be
installed on your computer in advance. Details can be found on
the ActiveSync help pages.


2.2.2.     USB cable
The connection between your computer and your Embroidery
System has to be done with the standard USB cable.
Plug the cable into the USB ports on the artista 200 and your
computer.
Microsoft ® ActiveSync is automatically activated and connects the artista 200 to your computer.


   Whenever a connection fails, plug in the cable again and the
   automatic connecting process starts - check the green
   symbol in the task bar on your computer.




2.3. Setup Connections for artista 165 to 185 and R/W box
The communication between BERNINA® Embroidery Software and BERNINA® Embroidery System
devices like

   ♦     artista 165, 170, 180 or 185 sewing computer with embroidery module
   ♦     BERNINA® artista Design Card

will be done by a serial interface R232. A serial cable is used for the physical connection between your
computer and the BERNINA® Embroidery System.

3.1.3.    Click Embroider

         The design is downloaded and opened on your embroidery system. When the transfer is

          Instead of Embroider use the download function to copy the design to the active storage

5. Administering your designs
Designs can be stored in different storage devices on the embroidery system or your computer.
Designs can be renamed, deleted or even moved to other folders. The design files are arranged in
folders and can be handled in a manner similar to file manager.
Some limitations have been placed to ensure proper use.


5.1. Startup Design Manager
                      Use Card/Machine Read on the file menu to start the design manager.




The dialog shows two design file areas.
♦ Upper area shows designs in a storage device like the BERNINA® embroidery system, personal
   design card or CD-ROM.
♦ Lower area shows designs on your computer.

With this dialog you can copy single design files in both directions. Every time a transferable design is
selected, the appropriate arrow button gets activated, shown by a color change from gray to blue, and
the copy operation can be performed by pressing this arrow button.

      This dialog is also used for editing a design on your embroidery system using the edit button.

5.2. Designs and Folders


5.2.1.     Licensed Designs
           ®
BERNINA Embroidery Designs have two license Level. This levels are shown by the thumbnails.

         Level 1: Copy protected design
         This designs can be edited in the artista 200 and the BERNINA® Embroidery Software.
         Designs can only be saved to the internal memory of the artista 200 (not to computer or
         Personal Design Card).

         Level 2: Copy and change protected design
         This designs can not be edited. Designs can only be saved to the internal memory of the
         artista 200 (not to computer or Personal Design Card).



5.2.2.     Design Types and Formats
         BERNINA® offers several type of designs. The thumbnails look different. Alphabet designs are
         marked with an "α" and two different design file formats can be recognized on the thumbnail
         by the letters "Exp" or "Art".



5.2.3.     Design Selection
            Designs can be found on three different storage devices.
            A design is selected by a mouse button click.



Whenever a design is selected, it will be displayed in the Selected Design
field.



5.2.4.     Memory usage for designs
The user has full control over the actual free memory space for designs on the embroidery
system. The usage bar shows the percentage of memory used. A yellow line indicates the
memory forecast depending on the selected designs.

5.2.5.    Folder navigation
The navigation is very similar to typical hierarchical structures.

                                         To get into a folder just click on the folder object or a tab.

      You press on this button to move to a parent folder.

      Use this button to get access to all folders in your computer network.



5.2.6.    New folder
      A new folder can be defined by pressing this button. The name of the new folder starts with the
      standard name "folder". It is recommended to change the name to meaningful text.

5.2.7.    Rename file or folder
      Each object can be renamed by pressing this button. The existing name is highlighted and can
      be edited. The rename function is also available by using the right mouse button and clicking on
the object.

5.2.8.    Delete file or folder
      Selected objects can be deleted by pressing this button. The delete function is also available by
      using the right mouse button and clicking on the object.

5.2.9.    Design information
      Information on a design can be displayed by pressing
      this button. The properties function is also available by
using the right mouse button on the object. Width, height,
number of stitches, number of colors and size of a single
design are displayed.




5.2.10. Copy file or folder

                       Selected objects can be easily copied by pressing the arrow button.

5.4. Limitations
To ensure proper use, some limitations have been applied in administering your designs:

♦   The three main folders "Alphabets, Motifs, My Designs" can not be deleted or renamed.

♦   Alphabets in folder "Alphabets" can not be deleted or renamed.

♦   Only six folders can be created on the artista 200 Embroidery System.
